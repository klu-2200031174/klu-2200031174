## About

I build full-stack applications, and lately I've been more interested in
measuring AI systems than in shipping them. My current project is a support
agent over 2.8M tweets, where the most useful result was discovering that most
of its apparent improvement was an artifact of how it was being judged.

- Working with Python, React and Spring Boot
- Currently focused on LLM evaluation — blinded judging, ablations, honest error bars
- Open to internships and new-grad roles

### twitter-support-agent

Support triage and reply drafting for @AmazonHelp, on the Customer Support on
Twitter dataset (2.8M tweets). Two stages: intent classification, then reply.

**0.797 macro-F1** on intent — but the finding I care about is that a blinded
ablation showed ~77% of the headline gain was judge bias, retrieved context
didn't help at all, and the honest ceiling on safe automation is 6.7% of
traffic.
